# 🛒 Supermarket Sales Dashboard — Power BI Project

## 📊 Overview
This Power BI dashboard provides a detailed visualization of supermarket sales performance using data imported from Excel.  
The project aims to transform raw transactional data into meaningful insights that help management understand sales trends, customer behavior, and profitability.

---

## 🎯 Objectives
- Analyze total sales and revenue growth across time.
- Identify top-performing branches, products, and customer segments.
- Evaluate payment preferences and customer satisfaction ratings.
- Provide clear KPIs for quick decision-making.

---

## 🧠 Tools & Technologies
- **Power BI** — Data modeling, DAX measures, and dashboard design  
- **Microsoft Excel** — Data import and preprocessing  
- **DAX (Data Analysis Expressions)** — Calculations for KPIs and metrics  
- **Data Visualization** — Interactive charts, slicers, and reports
